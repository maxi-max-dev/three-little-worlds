# 小小世界 · 三款核心玩法试玩

[在线试玩](https://maxi-max-dev.github.io/three-little-worlds/)

- **再拿一件**：90 秒采宝撤离。风羽、重钟、潮灯改变路线；在能力、重量和带回的宝物之间取舍。
- **九格小世界**：十二轮选牌、放置、替换与升级。水、树林、果园和蜂房形成连锁收成。
- **一分钟人生**：每代 60 秒。种树、修桥、跨代取晨光，再过桥修好并点亮灯塔。

方向键或 WASD 移动；拿宝按 E，人生按住 E；P 暂停。支持屏幕方向与行动按钮。九格点击卡牌，再点击棋盘位置。音效默认关闭，可在右上角打开。

记录仅保存在当前浏览器。拿宝和九格保存最佳成绩；人生保存世界建设与换代状态。刷新进行中的生命会从本代出生点重新开始，随身物资不恢复，已完成建设保留。

## 本地运行

无需安装依赖。运行 `npm start`，打开 `http://127.0.0.1:8770`。运行 `npm test` 可执行 12 项规则检查。

网站使用原生 HTML、CSS、JavaScript 和 Canvas；图形与可选音效均由代码生成。GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留原始静态文件。

这是用于比较核心乐趣的 Demo，尚未完成难度平衡或真人复玩验证。
